Single-cell model with transient inhibition

Equations for the Brian2 tutorial

Model overview

The spontaneously firing Hodgkin–Huxley cell is extended with a rectangular, conductance-based inhibitory synaptic event. Positive current is depolarizing:

Cm dV/dt = INa + IK + IL + Iinh
INa = ḡNam3h(ENa−V),   IK = ḡKn4(EK−V)
IL = gL(EL−V),   Iinh = ginh(t)(Einh−V)

Since Einh = −80 mV, the synaptic current is normally negative and hyperpolarizing.

Synaptic event

For onset ton and duration Δt, the inhibitory conductance is a rectangular pulse:

ginh(t) = ḡinh   if   ton ≤ t < ton+Δt;   otherwise 0.

Tutorial settings: ton = 0.5 s, Δt = 0.05 s, and ḡinh = 2 mS/cm². Students can edit all three values.

Gating dynamics

dx/dt = αx(V)(1−x) − βx(V)x,   x ∈ {m, h, n}

With V in mV and rates in ms−1:

αm = [(V+40)/10]/[1−e−(V+40)/10],   βm = 4e−(V+65)/18
αh = 0.07e−(V+65)/20,   βh = 1/[1+e−(V+35)/10]
αn = 0.1[(V+55)/10]/[1−e−(V+55)/10],   βn = 0.125e−(V+65)/80

Initial conditions and spike measurement

The cell begins at V(0) = −65 mV with each gate at x∞ = αx/(αx+βx). Spikes are measured at upward crossings of the operational sodium-activation threshold −55 mV. Since Hodgkin–Huxley activation is continuous, this is a pedagogical measurement threshold rather than a hard channel switch; voltage is not reset.
