Lobster STG AB/PD model with transient LP inhibition

Brian2 student tutorial based on Prinz, Bucher & Marder (2004)

Scope and selected cell

The biological pacemaker kernel contains one anterior burster (AB) and two pyloric dilator (PD) neurons. Following the paper, they are represented by one single-compartment AB/PD model. This lesson selects AB/PD model 3; the paper reports five valid AB/PD conductance combinations.

Membrane and calcium equations

Area = 0.628×10−3 cm²; C = 0.628 nF; τCa = 200 ms; f = 14.96 µM/nA; [Ca]0 = 0.05 µM; [Ca]out = 3 mM. Reversals are ENa = 50, EK = −80, EH = −20, and Eleak = −50 mV; ECa is dynamic.

Transient LP→PD glutamatergic inhibition

Isyn = gss(V−Es),   ds/dt = (s∞−s)/τs
s∞ = [1+exp((Vth−VLP)/Δ)]−1,   τs = (1−s∞)/k−

For LP glutamate, the paper specifies Es = −70 mV, k− = 1/40 ms−1, Vth = −35 mV, and Δ = 5 mV. It tests gs ∈ {0, 3, 10, 30, 100} nS; this lesson uses 30 nS. The settings dictionary controls an idealized LP active waveform (VLP = 20 mV active, −60 mV otherwise).

Initialization: The original database loaded saved limit-cycle states. This standalone tutorial instead performs a 5 s unrecorded settling run. The −20 mV spike threshold is only a measurement convention; voltage is never reset.
