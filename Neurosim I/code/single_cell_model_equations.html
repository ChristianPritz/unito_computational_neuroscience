Single-cell conductance model

Equations for the Brian2 tutorial

Overview

The model is one Hodgkin–Huxley neuron with a fast sodium conductance, a delayed-rectifier potassium conductance, and a passive leak conductance. The leak reversal potential is deliberately set to −30 mV. At the initial voltage (−65 mV), the leak current is inward and depolarizing, so the cell fires without an additional injected current.

Membrane equation

Positive current is defined as depolarizing:

Cm dV/dt = INa + IK + IL
INa = ḡNa m3h (ENa − V)
IK = ḡK n4 (EK − V)
IL = gL (EL − V)

The variables m and h describe sodium activation and inactivation; n describes potassium activation.

Gating variables

dx/dt = αx(V)(1 − x) − βx(V)x,   x ∈ {m, h, n}

With V in mV and rates in ms−1:

αm = [(V+40)/10] / [1−e−(V+40)/10],   βm = 4e−(V+65)/18
αh = 0.07e−(V+65)/20,   βh = 1/[1+e−(V+35)/10]
αn = 0.1[(V+55)/10] / [1−e−(V+55)/10],   βn = 0.125e−(V+65)/80

Brian2 evaluates the removable singularities in αm and αn with its numerically stable exprel function.

Initial conditions and spike detection

The voltage starts at V(0) = −65 mV. Each gate starts at steady state:

x(0) = x∞(V(0)) = αx(V(0)) / [αx(V(0)) + βx(V(0))]

A spike is counted when V crosses the operational sodium-activation threshold of −55 mV upward. Hodgkin–Huxley sodium activation is continuous, so this is a pedagogical measurement threshold rather than a hard channel switch. Action potentials are generated by the conductance dynamics, and voltage is never reset.
